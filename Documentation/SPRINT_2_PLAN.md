# Sprint 2: Multi-Platform Controls & Basic HUD

**Duration:** Dec 29, 2024 - Jan 11, 2025 (2 weeks)
**Branch:** sprint-2-controls

## Sprint Goal
Game controllable on all target platforms (PC, WebGL) with basic UI feedback

## User Stories
1. As a player, I can control the car with keyboard, gamepad, or touch
2. As a player, I can see my current speed on screen
3. As a player, I can see my current cash balance
4. As a player, the camera doesn't clip through terrain

## Tasks Breakdown
- [ ] Install Unity Input System package
- [ ] Create InputActions asset (keyboard + gamepad mappings)
- [ ] Implement Cinemachine camera with collision detection
- [ ] Create UI Toolkit HUD document
- [ ] Add speedometer component
- [ ] Add cash display component
- [ ] Test on WebGL build
- [ ] Test with Xbox controller

## Definition of Done
- Game runs on PC with keyboard
- Game runs on PC with controller
- Game runs in WebGL browser
- HUD displays speed and cash
- Camera never clips through terrain
- No console errors
